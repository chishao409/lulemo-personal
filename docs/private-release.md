# 鹿了么私人版 1.8.1-private.1

基于 https://github.com/mengkuikun/luleme-app 的 main 源码快照修改，原始许可证为 MIT，保留 LICENSE。此目录的首个 Git 提交为修改前快照。

## 安装和迁移

已安装本仓库旧版私人版时，先备份记录，再直接覆盖安装1.8.1-private.1；无需卸载。本次沿用同一签名，版本代码递增为12。

首次从官方版迁移时：

1. 在原版导出 CSV，再使用“分享文件”把备份保存到电脑或独立于原版应用的目录。不要只把它留在应用内部目录中，卸载会删除应用数据。
2. 确认 CSV 文件可打开且包含原记录，再卸载原版。
3. 安装私人版 APK，进入设置的数据管理，导入 CSV。
4. 核对记录数量、日期和时长。主题、PIN、通知与提醒设置需要重新配置。

私人版保留包名 `com.lulemo.app`，与官方签名不同，所以首次必须备份后卸载重装。以后使用同一私人签名、递增 versionCode 的私人版可以覆盖更新。

## 使用

- 首页显示当前坚持与历史最长，坚持天数按距最近记录的开始时间每满24小时计算。最长间隔包含当前这段；没有记录时不推算起点。这是根据记录计算的间隔，漏记可以补录修正。
- “手动记录”可以指定准确日期和时刻，时长可留空。打开日历某天后可编辑或删除记录，间隔和坚持时长自动重算。
- 点“开始计时”后可锁屏或切后台，重新打开时用保存的开始时间恢复时长，不依赖后台持续运行。结束后确认保存，支持修正时间和时长；关闭确认页不会丢掉待保存计时，首页可再次确认，也可取消。
- 一次只运行一个计时任务。跨午夜计入开始那天；已保存的同一个计时任务不会重复生成记录。
- 在设置中分别开启每日次数、单次时长、两次间隔提醒，并填写个人阈值。次数达到或超过阈值时每天最多提醒一次，时长和间隔低于阈值时提醒；一次保存可合并多个条件。
- 今天的新增、编辑记录参与提醒。历史补录、导入、删除不弹提示，也不会重置当天已经提醒过的状态。调整设置不会立即补发提醒。
- 手机通知需系统授权。拒绝后仍有应用内提示；可在设置中重新开启。通知显示中性摘要，点击后在应用中查看详情。通知内容可自定义，请自行考虑锁屏上的可见性。
- 冷却期只提示，可选择“仍然记录”。
- CSV 保持原版列格式，补充保留小数分钟精度。CSV 和 WebDAV 保存记录，不包含提醒设置或未完成计时。

## 本地构建与后续更新

需要 Node/npm、JDK 17或21、Android SDK Platform 35、Build Tools 34.0.0。项目使用 AGP 8.7.3 / Gradle 8.9，匹配 API 35 与本机 JDK。

```powershell
npm ci
npm run typecheck
npm test
npm run build
npx cap sync android
.\scripts\prepare-signing.ps1
cd android
.\gradlew.bat assembleRelease
```

设置 `ANDROID_HOME` 和 `JAVA_HOME`，或在 `android/local.properties` 指定 SDK。本机首次执行签名脚本会生成私人密钥，默认保存在 `%USERPROFILE%\.lulemo-private-signing`。请备份该目录中的密钥和配置；失去它们会使后续版本无法覆盖私人版。源码与分发包不包含密钥或密码。

构建产物位于 `android/app/build/outputs/apk/release/app-release.apk`。交付用 APK 及校验信息放在工作区的 release 目录中。此版需在实际安卓手机上核对通知权限、锁屏恢复与备份迁移，浏览器测试不能替代真机验证。
