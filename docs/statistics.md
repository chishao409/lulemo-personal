# 日／周／月统计口径

1.8.0-private.1 新增，入口位于底部“统计”页。默认本月，支持日、周、月切换、历史日期选择、前后翻页和返回当前周期。新内容都放在统计页。

## 周期与记录

- 使用手机本地时区，日为本地零点至次日零点；周为周一零点至下周一零点；月为月初零点至下月月初。
- 周期含开始、不含结束。记录按开始时间归属；持续跨过午夜或月末也不拆分。
- 无效日期和未来记录不参与统计。当前周期只统计截至当前时刻已保存的记录；未来图表时段留空。
- 计时中的未保存任务不算记录。补录、编辑、删除、导入后，根据现有记录重新计算。

## 指标

- 次数：周期内有效记录数。
- 已记录总时长：填写了有效正数时长的记录之和，支持小数分钟；无时长数据时显示“—”。
- 平均时长：已记录总时长除以有有效时长的记录数量。未填写、0、负数、非有限数值不参与，不能当作0分钟。
- 时长覆盖数量：明确显示总次数和有时长的次数，防止把局部数据误认为全部。
- 间隔：全部有效历史记录按开始时间排序，相邻开始时间相减。相同开始时间可产生0间隔。没有前次的第一条记录排除。
- 间隔归属：后一条记录位于本周期，即计入本周期，前一条可以在周期之外。平均间隔按这些有效间隔取算术平均。
- 年度累计：当前年份的有效记录数，与年度12个月柱状图一致。全年月平均为年度次数除以12，不是仅对已经过去的月份取平均。

## 上期对比

当前周期比较上期相同日历进度。例如今天16日15:30，对比昨天截至15:30；本周五15:30，对比上周五截至15:30；本月16日15:30，对比上月16日截至15:30。

上月没有对应日期时，以整个上月为限，例如3月31日对比到2月末。周与日使用本地日历推进，避免把夏令时变化误当作固定24小时边界。已经结束的历史周期比较完整上期。页面显示上期实际比较范围。

次数变化为本期减上期；上期非0才显示变化百分比。上期为0时显示增加次数，二者均0时显示持平。总时长、平均时长各自受填写覆盖率影响，首版文字中的增减仅比较次数。

## 四类图表

| 图表 | 分组与数值 |
| --- | --- |
| 次数趋势 | 日按小时、周／月按天。已过去但没有记录的时段显示0；未来时段留空 |
| 持续时长趋势 | 与次数趋势同一时间轴，分别显示已记录总时长、平均时长；缺失时长留空，不跨缺口连接折线 |
| 发生时段分布 | 按本地开始时刻分为00–04、04–08、08–12、12–16、16–20、20–24时，各组含起点、不含终点 |
| 间隔分布 | 不足6小时、6～24小时、1～3天、3～7天、7天及以上；各组含下限、不含上限，1天按24小时计 |

每类图表提供详细数据表。次数与时长趋势共用一张表，放在时长趋势下方。图表分组不代表健康或疾病标准。

## 文字总结与隐私

本机按规则生成次数、记录天数、时长覆盖、平均值、集中发生时段和次数变化。并列时段明确写“并列”；少于3条记录注明样本较少。空周期说明“暂无记录”，不把未记录等同于没有发生。

不增加网络请求、账户或云端分析，不对次数增减进行好坏评价，也不据此推断疾病。

## 验证

统计测试覆盖本地周一起点、跨年、闰月、夏令时、周期边界、未来与无效记录、时长缺失、小数分钟、相同进度、上期零基线、跨周期间隔及分组边界、删改重算和年度口径。浏览器检查了390×844及360×640布局、浅深色、周期切换与数据表。安卓安装包仍需实际手机验证运行效果。
